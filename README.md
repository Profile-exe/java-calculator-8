# java-calculator-precourse

## 구현할 기능 목록

- CLI 입력
    - `Console` API 사용

- CLI 출력
  - 입력 안내 문구, 결과 문구 출력

- 커스텀 구분자 추출
  - "\\"와 "\n" 사이에 위치하는 문자는 커스텀 구분자로 사용
  - 정규 표현식 사용해 구분자 추출하기

- 피연산자 추출
  - 구분자 사이에 숫자들은 피연산자
  - 구분자는 한 문장에 여러개일 수 있음
  - 기본 구분자는 쉼표(,)와 콜론(:)
  - 따라서 구분자 목록을 두어 관리 및 피연산자 식별

- 피연산자들의 합 구하기

- 잘못된 입력에 대한 예외 발생 및 종료
  - `IllegalArgumentException` throw
